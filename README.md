# IT Operations Automation Toolkit

A Python-based automation toolkit that simulates real-world IT operations by replacing manual processes with automated workflows.

## Features

- Log file analysis with error detection
- API monitoring with alerting
- User onboarding automation
- Continuous execution (scheduled automation)

## Why this project?

This project demonstrates:
- Automation mindset (reducing manual work)
- Systems thinking (connecting multiple IT functions)
- Use of Python for real-world IT operations
- Monitoring and alerting concepts used in production environments

## Technologies

- Python
- REST APIs
- CSV & file handling
- Basic scheduling
- AI-assisted development

python main.py
